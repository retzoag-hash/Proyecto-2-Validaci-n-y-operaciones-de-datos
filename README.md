1) Crear un programa para identificar la longitud de una palabra ingresada. La palabra correcta debe tener entre cuatro y ocho letras. toma en cuenta las siguientes consideraciones: utilizando while mientras la cantidad de letras ingresadas sea menor que 20 , definimos la variable palabra  posterior contamos con len la palabra introducida
● Si la longitud de la palabra se encuentra en el rango de cuatro a ocho letras, se debe imprimir un mensaje que indique que la palabra es correcta: utilizando elif, si no si la cantidad de letras es mayor que 4 se imprime " palabra correcta" 
● Si la palabra tiene menos de 4 letras debe indicar un mensaje que diga: “Hacen falta letras. Solo tiene N letras” (siendo N el número de letras de la palabra):utilizando elif, si no si la cantidad de letras es menor que 4 se imprime "hace falta letras "
● Si la palabra tiene más de 8 letras debe indicar un mensaje que diga: “Sobran letras. Tiene N letras” (siendo N el número de letras de la palabra): utilizamos if, si la cantidad de letras es mayor que 8 se imprimirá  "sobran letras"
